Web Crawler 隐私政策

Privacy Policy · 最后更新 / Last updated：2026-10-07 · 适用版本：1.0.1

概述

Web Crawler（以下简称“本扩展”）是一款娱乐性质的浏览器扩展：在网页上绘制会爬行的机械蜘蛛动画， 可选地对页面元素做限时的视觉“感染”效果并自动还原。我们重视您的隐私，本扩展 不收集、不上传、不出售任何个人数据。

我们访问的数据

1. 本地存储（chrome.storage.local）

本扩展仅在浏览器本地存储：您的设置（开关、蜘蛛数量、速度、皮肤、音效、病毒效果参数等）、 您选择排除的域名列表、您主动输入的授权码及其校验结果。这些数据只保存在您的浏览器中， 卸载扩展即删除；不与任何第三方共享。

2. 网络访问

  • 内容脚本会在您访问的 http/https 页面上运行，用于绘制画布动画和（在开启“病毒模式”时） 修改页面元素的内联样式。页面内容不会被读取或发送到任何服务器。
  • 仅当您在设置中主动输入并验证授权码时，扩展会向授权服务器发送：授权码、 匿名随机设备标识符（用于限制一张码的激活设备数）、产品名与版本号。 除此之外，扩展不发起任何网络请求。
  • 音效、动画均在本地实时合成与渲染，不加载任何远程资源。

3. 我们不做的事

  • 不收集姓名、邮箱、浏览历史、IP 或任何可识别信息
  • 不使用广告 SDK、分析 SDK、像素追踪或指纹识别
  • 不访问标签页内容、剪贴板、Cookie 或表单数据
  • 不出售或共享数据（因为我们根本没有收集数据）

Privacy Policy (English)

Overview

Web Crawler is an entertainment browser extension: it draws animated mechanical spiders crawling over web pages and, optionally, applies time-limited visual “corruption” to page elements that automatically restores itself. This extension does not collect, upload, or sell any personal data.

Data we access

1. Local storage (chrome.storage.local) — only your settings, your per-site exclusion list, and the license key you voluntarily enter plus its verification result. Stored locally; deleted on uninstall; never shared.

2. Network access — content scripts run on the pages you visit solely to draw the canvas animation and (when virus mode is on) modify inline styles; page content is never read or transmitted. The only network request is the optional license verification (license key, random anonymous device id, product name, version) triggered when you voluntarily submit a key. Animation and sound are synthesized locally; no remote resources are loaded.

3. What we do NOT do — no collection of identifying data, no advertising/analytics/tracking/fingerprinting, no access to tab contents, clipboard, cookies or form data, no sale or sharing of data.

Payments

Pro license keys are purchased through an external payment provider (e.g. Stripe / Paddle / Lemon Squeezy); the developer never sees your full card number.
